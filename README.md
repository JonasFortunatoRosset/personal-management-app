## Personal App Manager

A personal management application designed to help people set goals, build better habits, track their progress, and organize their daily routines.

The project is being developed with a focus on creating a practical and genuinely useful application for managing different aspects of everyday life.

## Current Status

🚧 This project is currently under development.

The initial development will focus on the core goal management functionality.
New features will be introduced gradually as the application evolves.
